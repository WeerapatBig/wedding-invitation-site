  those-eyes.mp3

The audio toggle in the bottom-right of the page references this exact
filename. If the file is absent, the toggle stays visible but silently
falls back to an "unavailable" state on click (no broken-audio error
shown to the visitor).

Note on licensing: please use a copy you have the right to use.
Music streaming embeds (Spotify / Apple Music / YouTube Music) are
an alternative; replace the &lt;audio&gt; element in
src/components/AudioToggle.astro with an &lt;iframe&gt; embed if you
prefer that route.
